Single-File GitHub Deployment

Your entire site — including all HTML, CSS, JavaScript, project photos, contact forms, and this password-locked admin manager — is bundled into one single standalone file!

How to Deploy to GitHub Pages in 3 Steps:

  1. Click the green button below: "Download Standalone index.html".
  2. In your GitHub repository (krueger-website), upload or commit this index.html directly into the root of the repo.
  3. Go to your GitHub repo Settings → Pages → Branch: main (root) → Save. Your site is instantly live with zero build tools!
